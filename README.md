# 🌱 Node Farm Project

A simple Node.js project where I built a dynamic farm products website using pure Node.js (no frameworks).

## 🚀 Features

* Dynamic HTML templating
* Product-based routing
* JSON data handling
* Clean and responsive UI

## 🛠 Tech Stack

* Node.js
* HTML
* CSS

## 📂 How to Run

1. Clone the repository

```

```

2. Run the server

```

```

3. Open in browser

```
http://127.0.0.1:8000
```
